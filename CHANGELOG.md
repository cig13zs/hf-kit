### Added

- `npx skills add cig13zs/hf-kit` installs the agent skill. The skill now finds the kit on its own: the folder the agent started in, then `~/hf-kit`, and otherwise it clones the repository there.
- CI on every push: the tools' self-tests on Python 3.10 to 3.13, a check that the sound generators reproduce the committed effects byte for byte, a HyperFrames 0.8.77 lint of all 13 block demos, and a scaffold-and-lint pass for each of the 16 styles.
